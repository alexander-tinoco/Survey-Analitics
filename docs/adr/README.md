# Architecture Decision Records

Each ADR captures one significant decision: the context that forced it, the choice
made, and the consequences accepted. Records are immutable — a decision that stops
being true is not edited, it is superseded by a new ADR that links back to it.

Format follows [Michael Nygard's template](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
